关于论文排版的说明

    
    
      
  • 阅读顺序： 标题与摘要在最前，然后是左栏全文，最后是右栏——不会左右混读。
    • 
      
  • 双栏定位： 每栏的顶部按该栏第一个纵向紧密行序列的起始位置确定，而不是按文本块的高度猜测。
    • 
      
  • 中文折行： 同一栏内被排版折断的中文行会自动拼接，不会跨栏拼接。
    • 
      
  • 公式： 公式周边的文字与文本层中的符号会被提取；以图片绘制的公式可能不完整，这取决于 PDF 本身。
    • 
      
  • 扫描版 PDF： 如果 PDF 只有图片、没有文本层，工具会给出提示，这类文件需要先做 OCR。
    • 
      
  • 范围： 只提取纯文字，不提取图片、表格格式与参考文献排版。
    •

核心代码（网页版排序逻辑）

    
核心是阅读顺序重建：先按坐标把文字分组为行，识别通栏的标题/摘要，再分别确定左右两栏的起始位置，最后按「页眉 → 左栏 → 右栏 → 通栏结尾」拼接。中文折行只在同一栏内合并。

    

      

// 阅读顺序：标题/摘要 → 左栏全文 → 右栏全文
function pageToText(items, pageWidth) {
  const lines = buildLines(items);            // 按 Y 坐标分组为行
  const mid = pageWidth / 2;
  const full  = lines.filter(l => l.x0 < mid - 10 && l.x1 > mid + 10);
  const left  = lines.filter(l => !full.includes(l) && l.cx <  mid);
  const right = lines.filter(l => !full.includes(l) && l.cx >= mid);
  if (!left.length || !right.length) return joinLines(lines);

  // 每栏顶部 = 该栏第一个「纵向紧密行序列」的起始行，
  // 而不是由某个文本块的高度推断。
  const cut = Math.max(seqStartY(left), seqStartY(right));
  const header = lines.filter(l => l.y > cut + 2);
  const footer = full.filter(l => l.y <= cut + 2);
  return [joinLines(header),                 // 标题 + 摘要
          joinLines(left.filter(l => l.y <= cut + 2)),
          joinLines(right.filter(l => l.y <= cut + 2)),
          joinLines(footer)]
         .filter(Boolean).join("\n\n");
}

function seqStartY(colLines) {                // 第一个紧密序列的起始 Y
  const s = [...colLines].sort((a, b) => b.y - a.y);
  for (let i = 0; i < s.length - 1; i++)
    if (s[i].y - s[i + 1].y <= Math.max(s[i].h, s[i + 1].h) * 2)
      return s[i].y;
  return s.length ? s[0].y : 0;
}

#!/usr/bin/env python3
"""PDF 全文 -> TXT (UTF-8)。用法: python extract_pdf.py paper.pdf [-o out.txt]"""
import argparse
import fitz  # PyMuPDF

def page_text(page):
    blocks = [b for b in page.get_text("blocks") if b[4].strip()]
    if not blocks:
        return ""
    mid = page.rect.width / 2
    full  = [b for b in blocks if b[0] < mid - 10 and b[2] > mid + 10]
    left  = [b for b in blocks if b not in full and (b[0] + b[2]) / 2 <  mid]
    right = [b for b in blocks if b not in full and (b[0] + b[2]) / 2 >= mid]
    if not left or not right:
        return "\n".join(b[4].strip() for b in sorted(blocks, key=lambda b: b[1]))
    def seq_top(col):  # 第一个纵向紧密块序列的起始位置 = 该栏顶部
        s = sorted(col, key=lambda b: b[1])
        for a, b in zip(s, s[1:]):
            if b[1] - a[3] <= max(a[3] - a[1], 12) * 1.2:
                return a[1]
        return s[0][1]
    cut = max(seq_top(left), seq_top(right))
    head   = sorted([b for b in blocks if b[1] < cut - 2], key=lambda b: b[1])
    body_l = sorted([b for b in left  if b[1] >= cut - 2], key=lambda b: b[1])
    body_r = sorted([b for b in right if b[1] >= cut - 2], key=lambda b: b[1])
    foot   = sorted([b for b in full  if b[1] >= cut - 2], key=lambda b: b[1])
    return "\n\n".join(b[4].strip() for b in head + body_l + body_r + foot)

def main():
    ap = argparse.ArgumentParser(description="PDF -> TXT")
    ap.add_argument("input")
    ap.add_argument("-o", "--output")
    args = ap.parse_args()
    out = args.output or args.input.rsplit(".", 1)[0] + ".txt"
    doc = fitz.open(args.input)
    text = "\n\n".join(page_text(p) for p in doc)
    with open(out, "w", encoding="utf-8") as f:
        f.write(text)
    print(f"done: {doc.page_count} pages, {len(text)} chars -> {out}")

if __name__ == "__main__":
    main()

    


    
Gradio 界面版（app.py，可选）

    
需要在自己服务器上提供上传界面时使用（GitHub Pages 只托管静态网页，不能运行 Python）。运行 pip install gradio pymupdf 后执行 python app.py。

    

      

import gradio as gr
from extract_pdf import page_text
import fitz

def extract(file):
    doc = fitz.open(file.name)
    text = "\n\n".join(page_text(p) for p in doc)
    out = file.name.rsplit(".", 1)[0] + ".txt"
    open(out, "w", encoding="utf-8").write(text)
    return text, out

gr.Interface(fn=extract,
             inputs=gr.File(file_types=[".pdf"], label="PDF"),
             outputs=[gr.Textbox(label="全文", lines=20), gr.File(label="TXT")],
             title="PDF -> TXT").launch()
